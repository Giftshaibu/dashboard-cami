# dashboard-cami

This is a [Next.js](https://nextjs.org) dashboard project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the dashboard by modifying files in `app/` and `components/`. The page auto-updates as you edit the project.

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```
